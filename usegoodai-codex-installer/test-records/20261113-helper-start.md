# Windows 助手一打开就闪退的复现与修复（2026-11-13）

记录版本 1.0.0；快速接入助手 1.1.14（对比线上 1.1.13）。

## 起因

多台 Windows 11 电脑多次出现双击助手后一闪就退出、或者根本不出现，客户电脑上拿不到记录。以往的 Windows 测试只在 Windows Server 2022/2025 上跑；11-07 的 Win11 排查（windows-11-arm，开实时保护但不提交样本）各版都能打开，没有复现。

## 原因（Win11 上已复现）

助手的窗口是 WebView2（Edge 浏览器内核）显示的网页，所用的 Wails / go-webview2 有两处会无声退出或卡住：

1. WebView2 数据目录出问题（本次用“`EBWebView` 位置是一个文件”模拟）：控制器创建失败 `error creating controller with 80080005: Server execution failed`。go-webview2 把这句打印到图形程序没有的标准输出后 `os.Exit(1)`；线上 1.1.13 第一次打开不出窗口、进程卡在后台，再次双击把参数交给卡住的进程后立即退出——就是“一打开就闪退”，并且一直如此，直到重启电脑或结束进程。
2. 已开的助手不响应时，之后双击的助手发消息给它也卡住，没有窗口。
3. WebView2 完全起不来时什么都不出现，没有任何提示。

## 修改（1.1.14）

- 窗口一律用 CPU 绘制（`WebviewGpuIsDisabled`），并关闭 WebView2 渲染进程代码完整性检查（`WebviewDisableRendererCodeIntegrity`：安全软件注入未签名 DLL 时 WebView2 会结束自己）。
- 启动守护 `guard.go` / `guard_windows.go`：卡住的旧助手（启动 20 秒仍没有窗口，或 3 秒不响应）先结束；窗口进程 60 秒没就绪或异常退出时换新的 WebView2 数据目录再试，成功后写入 `safe-start.txt` 记住；仍打不开就弹窗：“窗口打不开：这台电脑上用来显示页面的 WebView2 组件出错，已经自动重试过一次。点「确定」改用命令窗口连接 Codex”，确定后运行网站的 `irm https://docs.usegoodai.com/install/codex.ps1 | iex`（链接带来的 Key 经 `USEGOODAI_KEY` 传入；Claude 链接则打开教程网站）。
- 窗口进程把标准输出接到启动记录，WebView2 错误原文不再丢失；启动记录改为始终追加。

## 测试

`tools/windows_start_check.ps1`，工作流“Windows 助手打开稳妥性测试”，GitHub windows-11-arm（Windows 11 Enterprise 10.0.26200，x64 程序经转译运行）。线上版从正式网站下载，两版都带浏览器下载标记。三轮（运行 43366149584、43371168253、43376174119）结果一致：

| 情况 | 线上 1.1.13 | 1.1.14 |
| --- | --- | --- |
| 家用默认 Defender（实时保护、云保护、自动提交样本、拦截不需要的应用）双击 | 5～6 秒打开 | 2～3 秒打开；无 Defender 或代码完整性拦截记录 |
| WebView2 数据目录损坏 | 第一次不出窗口、卡在后台；再次双击直接退出 | 结束卡住的进程，换新目录 2.7～3.4 秒打开；之后直接用记住的目录，2 秒打开 |
| 已开的助手不响应（进程挂起） | 再次双击卡住，没有窗口 | 结束卡住的进程，4～5 秒出新窗口 |
| WebView2 起不来（数据目录下不能新建文件夹） | 什么都不出现 | 约 61 秒后弹窗说明，点「确定」打开命令窗口 |

- 常规流程：“Windows 快速接入助手测试”（Windows Server 2022、2025）第一次打开、再次打开交给已开窗口、导入链接、上一稳定版运行时打开新版、生图升级按钮均通过（运行 43366149530）。
- Windows Server 2025 运行器上该稳妥性脚本三次都卡在打开带下载标记的程序这一步（原因未确认），已从矩阵去掉。
- Linux：守护的判定逻辑单测（旧实例处理、重试判定、记住数据目录、弹窗文字不含 Key）与 Go 全量通过。

## 未验证

- 被 Windows 智能应用控制或 360 等杀毒软件在运行前拦下的情况：程序没有运行，任何代码修改都无效，需要代码签名或误报申诉。
- 客户真实电脑；真实显卡驱动下的 CPU 绘制效果只在虚拟机上看过。
