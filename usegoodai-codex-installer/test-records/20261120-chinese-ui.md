# Windows 中文化按钮 1.2.2

记录版本 1.1.0 · 2026-11-21。Windows 10、Windows 11 x64 桌面验收完成；最终发布前执行同一提交的既有三项门禁。

## 实际增量

原有能力是助手 1.2.0 的工具区、运行互斥和日志目录，以及已发布的 Windows 中文化 1.1.6。本轮新增末尾按钮「一键中文化（没有梯子才需要）」、独立可见 PowerShell、按次完整转录、成功五秒关闭本次窗口。失败保留窗口，关闭后可再次操作。没有小记录框，继续复用原脚本的缓存、配置和 ChatGPT 关闭逻辑，没有新增网络后台、密钥设置或数据库修复。

1.2.1 为未单独发布的首个候选。截图发现长日志路径撑出横向滚动条，1.2.2 仅增加提示文字自动换行及对应版本信息；执行、记录和倒计时逻辑保持相同。因此 Windows 10 沿用已通过的 1.2.1 功能结果，只补测 1.2.2 显示；Windows 11 未通过组用 1.2.2 补齐。

原脚本部分失败分支输出失败后可能返回零，包装按转录中的明确结果判断，不把原脚本的零退出码当成功。日志预置 UTF-8 BOM，避免 PowerShell 5.1 将追加的中文写为 ASCII。新控制台不继承 GUI 已重定向的标准句柄，使实际输出留在可见 PowerShell。
