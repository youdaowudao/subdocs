# Windows 助手启动即退出排查

记录版本：1.0.0；日期：2026-11-11；助手候选：1.1.8，上一正式版：1.1.7。

用户确认最新版双击后立即退出，窗口来不及显示。截图为 Dell G15 5530，Windows 11 家庭中文版 25H2、构建 26200.9711，x64，Intel i7-13700HX、16 GB RAM、RTX 4060 Laptop 加 Intel UHD。未收到客户程序崩溃记录，尚未确认根因。

历史 1.1.5 回退没有确认根因。Windows Server 2022/2025 未复现，之前 Windows 11 ARM 运行器停留系统首次登录页面，不能作为 Win11 x64 原生窗口通过的证据。

1.1.8 是兼容性及诊断候选：默认软件渲染、独立 `webview-compat-v1` 缓存，保留旧缓存和用户配置；记录版本、系统、WebView2 及启动阶段。`--system-gpu` 仅供同一候选的排查对照，不修改系统或其他应用的硬件加速设置。日志限单份 256 KiB，保留最近 20 份，不读取真实密钥或输出桥接调用参数。

本地 Go 回归及 Windows x64 交叉构建已执行，原生 Windows 候选测试待运行。发布成品尚未同步，不将候选或预览称为正式站已发布。

客户这台 Windows 11 x64 双显卡实机：未验证；真实中转鉴权、计费、上游连通性和完整 Codex 桌面任务：未验证。正式下载暂保持 1.1.7，不因托管运行器成功就宣称故障已修复。
