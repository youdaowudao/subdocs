### 桌面网络与重复运行：进行中

[当前测试](https://github.com/youdaowudao/subdocs/actions/runs/44676654610)。六种网络 × 假 Key 接入工作区/未登录页，共 12 组；每组依次在开着、再次运行、关闭时运行，再连续运行 5 次，计划 96 次。

- 连接拒绝：Windows 防火墙阻断程序外联。
- 连接黑洞：相关域名指向 `192.0.2.1`。
- 持续无响应：域名指向本地 TCP 替身，接受 TLS 连接后 300 秒不回复。
- 解析失败：本地 DNS 返回 NXDOMAIN。
- 解析污染：相关域名指向错误的回环地址。
- 正常联网：运行器原网络。

每次记录总耗时、输出最大间隔、原进程关闭时间、前次缓存是否保留、窗口截图和中文文本、正常重开后状态，以及剩余进程和监听者。最终以全部完成后的报告为准；中止组不计通过。

### 测试中修正的采集问题

- DNS 场景原先选到了没有 IPv4 DNS 配置的虚拟网卡：改为只设置实际 DNS 对象，测试结束恢复。
- 实时读取子进程输出文件撞上文件占用：改为仅读文件长度，子进程退出后再读正文。
- 复用函数时动态脚本块的 `PSScriptRoot` 为空：显式保留测试目录。
- 失败专项检出自动转换换行：检出前关闭 `core.autocrlf`，核对原始字节重跑。

以上均为测试脚本或运行器检出问题，不能计为工具通过，也不能直接当成用户故障原因。失败和中止记录保留在 GitHub 与本地 `.git/local-archive/windows-chinese-20261120/`。
