Antigravity App Linux 测试候选（不需要 sudo）

1. 下载并解压官方 Antigravity App 2.15 或以上版本：https://antigravity.google/download
2. 彻底关闭正在运行的 Antigravity；解压本候选，打开终端进入解压目录。
3. 运行 ./usegoodai-antigravity-linux-x64 connect --app "/官方解压目录/Antigravity-x64/antigravity" ，按提示粘贴 Gemini 分组 Key。
4. 以后用 ./usegoodai-antigravity-linux-x64 open 打开已接入的官方 App。
5. 恢复官方登录：./usegoodai-antigravity-linux-x64 restore ，彻底退出后从官方入口打开。

本候选不修改 App 本体，不在系统目录写配置。只支持 Linux x86_64。
