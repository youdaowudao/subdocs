# Codex 改中文版

开着梯子联网时，Codex 桌面版默认就是中文，不用操作。没有梯子时，运行下面对应系统的命令。

Windows：按 Win 键，输入 `PowerShell`，按回车打开，粘贴运行：

```powershell
irm https://docs.usegoodai.com/install/chinese.ps1 | iex
```

Mac：按 Command + 空格，输入「终端」，按回车打开，粘贴运行：

```bash
curl -fsSL https://docs.usegoodai.com/install/chinese.sh | bash
```
